# Competitive intelligence

## The finding that reframes everything else

The top of this ecosystem is not model engineering. Clustering the signal set by what
each project actually is: skills packaging for coding agents dominates, curated lists
come second, and messaging-channel bridges come third. The single highest-starred
project in the entire scan contains ten markdown files and no code.

**The winners package and distribute. They do not train.**

## Where the weaknesses are

**HKUDS/OpenSpace** — skill quality is scored on outcomes it observed, so a skill used twice has a score with no confidence attached to it

**openmemind/memind** — Java, which is a hard boundary against a Python engine — integration means a network hop and a second runtime to operate

**facebookresearch/HyperAgents** — CC BY-NC-SA 4.0 is non-commercial — it cannot be built on by a business at all, and the ShareAlike term would infect anything derived from it

**neo4j-labs/create-context-graph** — Neo4j is a heavy operational dependency for a small team

**InternLM/WildClawBench** — 60 tasks is small enough that a few task-specific fixes move the ranking

**cisco-ai-defense/defenseclaw** — Go gateway plus Python CLI is two runtimes to operate

**slowmist/slowmist-agent-security** — documentation cannot be executed, so nothing here is measured

**patoles/agent-flow** — visualises one agent runtime's hooks, so it is coupled to that runtime's format

**saltbo/agent-kanban** — FSL-1.1-ALv2 is not open source today; it becomes Apache-2.0 only after two years

**soulduse/ai-token-monitor** — reports spend without reducing it — it is a thermometer, not a thermostat

**oguzbilgic/agent-kernel** — +1.8% over 82 days — attention has moved on

**Ataraxy-Labs/opensessions** — tmux-only, which caps the addressable audience

**ovoment/ovo-local-llm** — +2.0% over 82 days — effectively flat

**slavingia/skills** — no licence file, which means all rights reserved — it cannot be reused

**alvinunreal/awesome-opensource-ai** — a list has no defensibility; the next list replaces it

## Where the room to surpass is

Three weaknesses recur across the entire set and none of them is hard:

1. **Reporting without deciding.** Spend monitors draw charts; none computes the point
   past which a routing choice stops saving money. Observability tools show what
   happened; none attaches what it cost.
2. **Scores without denominators.** Security frameworks list attack categories with no
   measured detection or false-positive rate. Benchmarks publish accuracy with no
   refusal column, so a confabulating system ranks respectably.
3. **Visibility mistaken for control.** Boards show that an agent claimed a task;
   approvals are not bound to the proposal that was approved, so a plan can change
   after sign-off and proceed under the old authorisation.
