Generated by `engine/scripts/invariant_map.py`. Do not edit.

**8 of 11 rules have a predicate that runs.** 3 are declared unenforceable with a reason. 0 breaches. 2 allowlisted exceptions.

Before this file existed the answer to *how many of this repository's rules are checked* was zero, and nobody knew the denominator either. CLAUDE.md states 31 rules, 21 of them phrased as never/must-not/refuses. Two of the five defects that prompted this were direct violations of rules written in that document — greppable in minutes, sitting there because nothing grepped.

**A rule with no checker and no stated reason fails this script.** That is the anti-Goodhart mechanism: without it, this file becomes a second copy of CLAUDE.md that renders beautifully and enforces nothing.

### `money_is_int_picos`

Money is int pico-dollars (1e-12 USD). Never introduce a float currency path.

*Paid for by:* obs/trace.py recorded float(span.cost.picos) into a float64 counter; exact only below 2**53 picos = $9,007.20, on a CUMULATIVE metric

Micro-dollars round cheap-model tokens to zero, so a router that saves money reports saving nothing. The same rounding erases a half-micro-dollar tool called a thousand times.

### `time_is_injected`

Time comes from an injected Clock. Nothing calls datetime.now() or time.monotonic() directly.

*Paid for by:* guard/sandbox.py read time.monotonic() three times, so duration_seconds was unmockable and no test ever asserted on the field

The allowlist is the number to watch. Two entries that each name a working injection point is a boundary; five entries with vague reasons is a rule that has quietly stopped applying.

- **allowed** `engine/src/omnex/evals/runner.py` — Runner.run(now="") is the injection point and the suite uses it; the default only stamps a report timestamp, which nothing branches on.

- **allowed** `engine/src/omnex/llm/catalog.py` — age_days(today=None) and is_stale(today=None) take the date; the catalogue is a value object and threading a Clock through it would be heavier than the parameter it already has.

### `ordered_strenum_writes_all_four`

Any StrEnum compared with < or > must define all four comparison operators explicitly.

*Paid for by:* factory.Stage — inherited string comparison makes Stage.DEPLOY < Stage.IDEA true, and @total_ordering fills in nothing because all four operators are already inherited

The failure is silent and confident: a pipeline ordered by inherited string comparison permits every backwards move whose stage name happens to sort earlier, and the check still reads as working.

### `one_symbol_resolver`

Symbol resolution lives in omnex.core.symbols and is imported, never copied.

*Paid for by:* ontology_map.py, node_map.py and omnex.factory were about to hold three copies of one four-line check

The splitter is what a second copy costs: a quadratic fixed in the engine survived in citegate for a further commit.

### `twin_splitters_agree`

The sentence splitter exists twice on purpose; the two copies must behave identically.

*Paid for by:* the abbreviation sets diverged by dr./mr./ms. while the two FUNCTIONS stayed line-for-line identical, so citegate split "Mr. Lee and Ms. Park disagreed." into four fragments

citegate ships dependency-free and may not import the engine, so the duplication stays. What changes is that a convention held it before and a check holds it now.

### `zero_required_dependencies`

engine/pyproject.toml declares no runtime dependency; heavy libraries sit behind Protocol adapters as optional extras.

*Paid for by:* stated in CLAUDE.md since the first commit and never verified by anything

This is what makes the suite runnable on a bare interpreter, which is in turn why it gets run. The first required dependency is the one that quietly ends that.

### `live_listings_are_covered`

A listing that is live may not promise more images than QC has passed.

*Paid for by:* the EUR49 Complete Vault sells "170+ images" while the four QC manifests total 80 — a 90-image shortfall a buyer would discover after paying

Scoped to LIVE offers on purpose. "You must have 170 images" would be red until the day they exist, and a permanently red build is one people learn to ignore — the exact failure this registry was built against. `live` mirrors registry.ts's `enabled`: nothing sells today, so nothing is violated today, and the gate bites the moment somebody publishes. packs/listing_check.py reports the shortfall for every offer regardless, live or not.

### `bindings_carry_no_credentials`

An n8n binding names a credential and never carries one, and a binding may not claim confirmation without a person's name and a date.

*Paid for by:* an emitted workflow JSON is committed and shared; branch XI's whole gap is that a compiler with no supplied configuration either ships placeholders or invents the endpoint and the key

Two rules in one predicate because they fail together. compile/n8n.py scans the document it emits, but that document is momentary; this scans engine/ontology/n8n_bindings.json, which is the file that gets pushed. The confirmation half matters because `require_confirmed=True` is what stands between an unattended workflow and a shape nobody has seen work — a confirmation with nobody behind it is the only way that gate opens by accident.

## Declared unenforceable

Listed rather than dropped. A rule nobody can check is still a rule, and hiding it makes the enforced count look better than the repository is.

### `limitations_are_passing_tests`

A stated limitation is kept as a passing test rather than a paragraph.

*Why no predicate:* Whether a green test is an honesty anchor or an ordinary assertion is a judgement about intent, and a checker keying on names would be satisfied by renaming a test.

### `refusals_name_every_condition`

A refusal names every failing condition at once, not the first.

*Why no predicate:* Requires knowing that a function is a refusal and that its checks are independent. Every mechanical proxy — counting raises, looking for early returns — flags correct code and misses the real cases.

### `docstrings_name_the_failure`

Docstrings explain why, and name the failure the code prevents.

*Why no predicate:* A length or keyword check would be satisfied by padding, which is worse than no check: it converts a real convention into a quota.
